🚀 Ryzen Mobile Unleashed
A lightweight Python-based utility to manage and monitor AMD Ryzen™ Mobile processors' power limits (TDP) in real-time.

✨ Key Features
Modern UI: Built with CustomTkinter for a sleek, high-tech aesthetic (Supports Light/Dark mode).

Precision Control: Adjust STAPM, Fast, and Slow power limits on the fly using the RyzenAdj engine.

Real-time Monitoring: Track CPU temperature and system load directly from the dashboard.

Portable: No installation required, runs as a standalone .exe.

Stealth Mode: Minimize to system tray for continuous, non-intrusive operation.

🛠️ Tech Stack
Language: Python 3.10+.

GUI: CustomTkinter.

Backend: RyzenAdj Engine.

Libraries: psutil, wmi, pystray, PIL.

🖥️ Requirements
Windows 10/11 (64-bit).

AMD Ryzen™ Mobile Processor.

Administrator Privileges (Required to access CPU registers).

⚠️ Disclaimer
This tool modifies system power limits. Use it wisely to avoid overheating. The author is not responsible for any hardware damage.
